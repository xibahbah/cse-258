## Working notes

For an observed rating, a factor model uses μ+b_u+b_i+p_u·q_i. For implicit feedback, BPR compares positive and unobserved items within a user. With one relevant held-out item at rank r, HR@K is 1 if r≤K and 0 otherwise. NDCG@K is 1/log₂(r+1) in that same case and 0 otherwise. Mask training items before ranking.
