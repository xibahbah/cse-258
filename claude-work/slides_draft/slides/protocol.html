Section 1 · Evaluation and validity

How we evaluate, and how we know the evaluation is sound

Protocol

Per user: 1 test game, 1 validation game, the rest for training.

Every model ranks the full catalog. No sampled negatives.

HR@10, NDCG@10, MRR, AUC, each with a 95% bootstrap interval.

Validity checks

Random must sit at chance: 0.0027 measured vs. 0.0028 expected.

Metric code passes known-answer tests.

Results must survive a second implementation, re-drawn splits, and a different hidden game.

Baselines: Random as a sanity check, Popularity as the non-personalized bar every model must clear.
