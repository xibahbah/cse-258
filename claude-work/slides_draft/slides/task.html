Section 1 · Predictive task

Recover a hidden game the user really played

Input

The games a user has played. No timestamps, no metadata.

Output

A ranking of every game the user has not played. Top 10 are the recommendations.

Judged on

Where one hidden played game lands in that ranking.

The hidden game is a random one, not the latest. This is not next-game prediction, and we do not claim it is.

Why ranking and not rating prediction: Steam has no star ratings, only ownership and playtime.
