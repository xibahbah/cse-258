# Case 258: The Missing Game

Pixel-art presentation for the video. Live: https://xibahbah.github.io/cse-258/

- Open `index.html` in a browser (no build step, no network needed).
- Right arrow / space: next step. Left: back. `]` / `[`: next / previous floor. `F`: fullscreen.
- Renders at 640x360 and scales up with whole pixels, letterboxed to 16:9. Record fullscreen at 1080p or above.
- `engine.js`: renderer, panel, transitions. `s01.js`–`s12.js`: one file per floor. `text.js`: every line in the panel.
- Team names: `TEAM` at the top of `engine.js`.
